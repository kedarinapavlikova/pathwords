# 🌹 PathWords

A rose garden word puzzle game built for kids — and anyone who loves words.

PathWords is a browser-based word game inspired by the New York Times Spelling Bee. Nine letters bloom in a garden grid, and players tap them to build words. Find as many real English words as you can, score points for longer words, and watch your garden grow with every discovery.

Built with love for Rosie. 🌸

---

## How to Play

1. You get 9 letters arranged in a 3×3 grid
2. Tap any letters in any order to build a word
3. Hit **Check Word** — if it's real, you score points!
4. Longer words = more points
5. Hit **New Game** for a fresh set of letters

Words must be 2 or more letters. Any real English word counts.

---

## Features

- 🌸 Rose garden theme with the Wildflower Meadow colour palette
- 🔤 9-letter grids with balanced vowel-to-consonant ratios so words are always findable
- 📖 Full English dictionary validation via [dictionaryapi.dev](https://dictionaryapi.dev) — no word gaps
- ⚡ Local word cache so common words are accepted instantly
- 🎉 Confetti and animations on every correct word
- 📱 Mobile-first design with large touch targets
- 🌐 Works in any browser, no install needed

---

## Tech

A single self-contained HTML file — no frameworks, no build step, no dependencies. Just open it in a browser and play.

Word validation uses the free [Free Dictionary API](https://dictionaryapi.dev), with a local fallback list for common words and offline play.
